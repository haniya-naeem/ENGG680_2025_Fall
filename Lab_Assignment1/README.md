Assignment 1: This assignment covers the fundamental concepts of python, such as variables, strings, lists, dictionaries, tuples, sets, and functions. A key part of this assignment is the application of Least Square Estimation(LSE)which shows how to fit polynomial models to data and analyze residuals for model accuracy.This assignment aim to equip students with the skills to write efficient Python code, analyze and visualize data, and apply both LSE and machine learning techniques to solve engineering problems.
